# Boojie Clear Chat

Boojie Clear Chat clears the currently selected World of Warcraft chat tab and its matching ElvUI saved history.

## Features

- Clears the currently selected chat tab
- Removes matching message types from ElvUI's saved chat history when ElvUI history is available
- Works without ElvUI
- Provides `/clear` and `/clearchat` commands
- Provides the shared `/rl` interface-reload shortcut

## Important

Clearing a chat tab cannot be undone. When ElvUI chat history is available, matching saved messages are also removed so they do not return after a reload.

## Installation

1. Download the zip file and unarchive it.
2. Place the `BoojieClearChat` folder inside:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Ensure it is properly installed by checking:

   `World of Warcraft/_retail_/Interface/AddOns/BoojieClearChat/BoojieClearChat.toc`

4. Enable Boojie Clear Chat from the AddOns menu on the character-selection screen.
5. Log in or type `/reload`.
